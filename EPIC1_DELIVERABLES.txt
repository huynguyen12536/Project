SECURITY FEATURES IMPLEMENTED
================================================================================

✅ Token Security
   - Secure random token generation (256-bit entropy)
   - SHA-256 hashing for storage (never store plain tokens)
   - 24-hour expiry configurable via properties
   - Single-use enforcement via is_used flags

✅ Password Security
   - BCrypt hashing via Spring Security
   - Password complexity validation (uppercase, lowercase, digit, special char)
   - 8-128 character length requirement
   - Tracking of last password change

✅ Account Security
   - Account lockout after 5 failed login attempts
   - 30-minute lockout duration (configurable)
   - Failed attempt tracking with IP address
   - Automatic unlock when successful login occurs

✅ Audit Trail
   - IP address captured on password reset
   - User-Agent captured for investigation
   - Timestamps on all security events
   - Immutable token records (never deleted, marked as used)

✅ Input Validation
   - DTO-level validation with annotations
   - Regex patterns for GitHub URLs, phone numbers
   - Field length validations
   - Email format validation
   - Password complexity validation

✅ Email Security
   - SMTP with TLS encryption
   - Credentials from environment variables (not hardcoded)
   - Email verification gate (ready for enforcement)
   - Verification link includes token (one-time use)
